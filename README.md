# Single-Page CV

A responsive single-page CV website built with semantic HTML and CSS.

🔗 **Live Demo:** [https://single-page-cv-kappa.vercel.app/](https://single-page-cv-kappa.vercel.app/)

## Features
- **Semantic HTML5:** Clean and accessible markup structure.
- **Custom CSS:** Built with modern CSS (Flexbox, Grid, CSS Variables) without relying on heavy frameworks.
- **Fully Responsive:** Optimized for mobile devices, tablets, and desktop screens.
- **Clean Architecture:** Organized file structure and modular styling.

## Technologies Used
- HTML5
- CSS3 (Custom Properties, Media Queries)
- SVG Icons
